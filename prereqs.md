title: Prerequisites
---

This lesson assumes you have a working knowledge of Python and some previous exposure to the Unix shell.

These requirements can be fulfilled by:

1. Completing a Software Carpentry R workshop - [Programming with R](https://swcarpentry.github.io/r-novice-inflammation/) **or** [R for Reproducible Data Science](https://swcarpentry.github.io/r-novice-gapminder/)
1. Coursework in or independent learning of both R and the shell.

### Terminal/Shell skills

The skill set listed below is covered in the Software Carpentry [Unix Shell](https://swcarpentry.github.io/shell-novice/) workshop . These skills can also be learned
through coursework or independent learning.

Be able to:

- Identify and navigate to your home directory.
- Identify your current working directory.
- Navigating directories using `pwd`, `ls`, `cd <subdirectory>`, and `cd ..`

### R skills

Be able to:

- Use the assignment operator `<-` to create variables of basic types (integer, double, logical, character).
- Perform basic arithmetic operations (e.g. addition, subtraction) on variables.
- Convert strings to numbers where appropriate.
- understand *tidy* data.
- Create a `data frame` and access its elements
- Create a `vector` using concatenation `c()` and use indexing to access vector elements.
- Use `paste()` and `paste0()`.
- Create a `list` and alter lists by appending, inserting, or removing values.
- Use indexing and slicing to access elements of vectors, strings, lists, and data frames.
- Use good coding practices to comment your code and choose appropriate variable names.
- Write a `for` loop that increments a variable.
- Write conditional statements using `if`, `else if` and `else`.
- Use comparison operators (`==`, `!=`, `<`, `<=`, `>`, `>=`) in conditional statements.
- Understand `logical` vectors.
- Read data from a file using `read_csv()`.
- Open, read from, write to, and close input and output files.
- Use `print()` and `length()` to inspect variables.

The following skills are useful, but not required:

- Apply a function to an entire R object or to a single vector axis.
- Write a user-defined function.
- Install libraries to extend base R functionality.

If you aren't sure whether you meet these requirements, please
get in touch with the instructors.
